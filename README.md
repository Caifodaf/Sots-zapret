> [!NOTE]
>
> ### О приложении
> Мы предостовляем удобное приложение для Windows 10\11, для управления профилей\стратегий с использованием WinDivert. Для оптимальной работы Youtube, Discord и других сервисов имеющих проблемы в работе.
> Графическая оболочка для обхода DPI-блокировок на базе [zapret](https://github.com/bol-van/zapret)


> [!WARNING]
>
> ### АНТИВИРУСЫ
> WinDivert может вызвать реакцию антивируса.
> WinDivert - это инструмент для перехвата и фильтрации трафика, необходимый для работы zapret.
> Он может использоваться как хорошими, так и плохими программами, но сам по себе не является вирусом.
> Драйвер WinDivert64.sys подписан для возможности загрузки в 64-битное ядро Windows.
>
> **Выдержка из [`readme.md`](https://github.com/bol-van/zapret-win-bundle/blob/master/readme.md#%D0%B0%D0%BD%D1%82%D0%B8%D0%B2%D0%B8%D1%80%D1%83%D1%81%D1%8B) репозитория [bol-van/zapret-win-bundle](https://github.com/bol-van/zapret-win-bundle)*
>
> Также файл jvm.dll может вызвать реакцию антивируса, из-за отсутвии подписи Microsoft(так как средств на это нет).
> jvm.dll - это основной файл библиотеки Java в ОС Windows, представляющий собой фактическую реализацию Java Virtual Machine (JVM). Он содержит код для загрузки, проверки и выполнения байт-кода Java, обеспечивая работу Java-приложений.
>
> В случае проблем с антивирусом добавьте папку с запретом в исключения, либо отключите детектирование PUA (потенциально нежелательных приложений). Например, в касперском есть галочка "Обнаруживать легальные приложения, которые злоумышленники часто используют для нанесения вреда". При аккуратной и правильной настройке исключений - рекомендуется настроить исключение, но если вы не до конца понимаете что делаете - рекомендуется отключить детект PUA.

> [!IMPORTANT]
> Все бинарные файлы в папке [`bin`](./bin) взяты из [zapret-win-bundle/zapret-winws](https://github.com/bol-van/zapret-win-bundle/tree/master/zapret-winws). Вы можете это проверить с помощью хэшей/контрольных сумм. Проверяйте, что запускаете, используя сборки из интернета!

## ⚙️Использование и Установка

1. Включите Secure DNS
    * В Chrome - "Использовать безопасный DNS", и выбрать поставщика услуг DNS (выбрать вариант, отличный от поставщика по умолчанию)
    * В Firefox - "Включить DNS через HTTPS, используя: Максимальную защиту", затем "Выбрать поставщика" и вписать URL поставщика вручную, например можно использовать `https://dns.google/dns-query` (т.к. поставщик Cloudflare может быть заблокирован)
    * В Windows 11 поддерживается включение Secure DNS прямо в настройках ОС - [инструкция тут](https://www.howtogeek.com/765940/how-to-enable-dns-over-https-on-windows-11/). Рекомендуется, если вы пользуетесь Windows 11

2. Скачайте exe-установщик со [страницы последнего релиза](https://github.com/Caifodaf/Sots-zapret/releases/latest)

3. Запустите установщик `sots_***_installer.exe` от имени администратора, и следуйте инструкции по установке.
   
4. Запустите приложение с рабочего стола.

5. Дождитесь загрузки профилей с сервера, после выберете нужный или запустите автоматическое сканирование. И нажмите запустить. 

> [!IMPORTANT]
> Установщик не имеет ни каких реклам или дополнительных приложений. Если вы беспокоитесь за несуществующую возможную установку чего либо иного кроме приложения, можете загрузить portable версию.

## ✨ Основные возможности

- 🖥️ **Графический интерфейс** - удобное управление обходом блокировок без командной строки
- 📦 **Множество профилей** - поддержка различных стратегий обхода (универсальные, для игр, Discord, YouTube и др.)
- 🔄 **Автоматическое обновление профилей** - регулярное обновление профилей из API
- 🎯 **Автоматический подбор профиля** - функция автоматического поиска рабочего профиля для выбранного сервиса
- ⚙️ **Гибкие настройки** - автозапуск, работа в трее, темы оформления, выбор языка
- 📋 **Управление whitelist** - возможность добавлять собственные домены для обхода в интрефейсе
- 🎮 **Поддержка игр** - специальные профили для игровых сервисов (LoL и др.)
- 🔒 **Безопасность** - работа на основе открытого исходного кода

## 🚀 Установка и использование

### Требования для работы приложения

- Windows 10\11 х64
- Права администратора (для работы WinDivert)
- Настроенный Secure DNS (рекомендуется)

### Первый запуск

1. При первом запуске приложение автоматически проверит обновления и загрузит профили обхода
2. Выберите профиль из списка или используйте функцию "Автоматический поиск"
3. Нажмите кнопку "Включить" для активации обхода
4. Проверьте статус - при успешном запуске индикатор станет зеленым

## 🎯 Основные функции

### Выбор профиля

Приложение поддерживает множество профилей для различных сценариев:

- **Универсальные профили** - базовые стратегии обхода, подходят для большинства случаев
- **Профили для игр** - специальная оптимизация для игровых сервисов (LoL и др.)
- **Профили для Discord** - оптимизированные настройки для работы Discord
- **Профили для YouTube** - специальные стратегии для обхода блокировок YouTube
- **Пользовательские профили** - возможность добавления собственных профилей в формате .bat или .txt

### Автоматический подбор профиля

Функция автоматического поиска позволяет:
- Выбрать целевой сервис (YouTube, Discord, LoL, универсальный)
- Автоматически протестировать доступные профили
- Найти оптимальный профиль для вашего провайдера и условий

### Управление whitelist

Вы можете добавлять собственные домены в список для обхода:
- Перейдите в Настройки → Список ссылок
- Добавьте домен (например: `example.com`)
- Приложение автоматически перезапустит сервис с новыми настройками

### Автозапуск

- Включите "Запускать с системой" в настройках
- Приложение будет автоматически запускаться при загрузке Windows
- Работа в фоновом режиме с возможностью отображения в трее

### Обновления

- Профлили для обхода проверяются на обновление при запуске приложения и загружаются автоматически. При этом если профиль что вы используете обновится, то не нужно беспоится профиль не перезапустится и не обновится(для его обновления перезапустите профиль самостоятельно). Также последний запущенный профиль записывается в last.txt в 
%LOCALAPPDATA%\Sots\profiles для его сохранения.

- При наличии обновления самого приложения ВРЕМЕННО, нужно будет обновлять его вручную. Для этого нажмите на кнопку обновить в приложении или самостоятельно перейдите на [страницы последнего релиза](https://github.com/Caifodaf/Sots-zapret/releases/latest) и загрузите и установите обновление.

## ❓ Часто задаваемые вопросы

### После запуска приложения ничего не происходит

Убедитесь, что:
- Приложение запущено от имени администратора
- Антивирус не блокирует работу приложения, а именно файл jvm.dll в %LOCALAPPDATA%\Sots\java
- Проверте наличие запущеного приложения в диспечере задач
 
### Бесконечное "подключение" к голосовому чату Discord

1. Откройте Настройки
2. Перейдите в раздел "Прочее"
3. Нажмите "Обновить список hosts"

### Обход не работает / перестал работать

1. **Попробуйте другой профиль** - разные провайдеры требуют разные стратегии
2. **Используйте автоматический подбор** - функция найдет рабочий профиль
3. **Проверьте Secure DNS** - убедитесь, что DNS через HTTPS включен
4. **Проверьте whitelist** - убедитесь, что нужный домен добавлен

### Не работает игра/приложение с включённым обходом

Некоторые приложения могут конфликтовать с обходом. Попробуйте:
- Временно отключить обход для тестирования
- Использовать профили, специально предназначенные для игр (скоро будут добавленны)
- Проверить настройки файрвола

### Античит ругается на WinDivert

WinDivert может определяться античитами как подозрительный компонент. Это известная проблема. Рекомендуется:
- Добавить приложение в исключения античита (если возможно)
- Использовать альтернативные методы обхода для игр
- Обратиться к разработчикам античита за решением

### Не работает YouTube

- Убедитесь что вы настроили Secure DNS.
- Отключите блокировщик рекламы, известно что YouTube начал с ними бороться.
- Попробуйте профили, специально предназначенные для YouTube

### Не работает Discord

- Желательно сначала узнать, на какой стратегии открывается сайт YouTube. Запустите эту стратегию.
- Проверьте Discord в браузере: https://discord.com/app. В браузере работает? Если работает, то можете пользоваться в нём.
- Если Discord и в браузере не работает, убедитесь что вы настроили Secure DNS, и после этого ещё раз пробуйте все стратегии. Бывает такое, что на одной стратегии YouTube работает, а Discord нет.
- Обновите hosts файл через Настройки → "Обновить список hosts"
- Попробуйте профили, специально предназначенные для Discord

### Как удалить

- Используйте стандартный установщик приложений в Windows. Или в корневой папке приложения unins000.exe.
- Если использовали portable, удалите папку приложения и также удалите папку с профилями %LOCALAPPDATA%\Sots
- Если у вас не получается удалить приложение, проверте что профиль отключен. Для этого запустите приложение и отключите профиль, после закройте его. Если у вас включен "работа в треи", нажмите по иконке Sots и выберите "Выход", после продолжайте удаление.

### Не нашли своей проблемы

* Создайте её [тут](https://github.com/Flowseal/zapret-discord-youtube/issues)

## 📝 Добавление собственных профилей

Вы можете добавлять собственные профили обхода:

1. Создайте файл `.bat` или `.txt` с конфигурацией профиля
2. Поместите файл в папку пользовательских профилей %LOCALAPPDATA%\Sots\profiles\custom
3. Профиль появится в списке доступных, как для запуска так и проверки.

Формат профилей соответствует стандарту zapret-win-bundle и zapret-discord-youtube.
